# Watchly — دليل الأفلام والمسلسلات 🎬

موقع على طريقة **السينما.كوم**: صفحة لكل عمل فيها القصة، والأبطال، وملخص الحلقات، والإعلان الرسمي، و**"تتفرج فين؟"** بروابط المنصات الرسمية.

- **التكلفة:** صفر (GitHub + Cloudflare Pages + Pages CMS، كلهم مجانًا)
- **لوحة التحكم:** تضيفي وتعدّلي من المتصفح، من غير كود
- **SEO:** عنوان ووصف لكل صفحة، Schema، sitemap، robots، صفحات تصنيفات
- **الإعلانات:** خانات جاهزة تحطي فيها كود AdSense أو Adsterra أو Monetag

---

## الخطوة ١ — ارفعي الملفات على GitHub (من غير ما تكتبي أي كود)

1. اعملي حساب على **github.com** لو مش عندك.
2. فوق على اليمين دوسي **+** ثم **New repository**.
   - Repository name: `watchly`
   - اختاري **Public** أو **Private** (الاتنين شغالين)
   - دوسي **Create repository**
3. في الصفحة اللي هتفتح، دوسي اللينك **uploading an existing file**.
4. افتحي فولدر `watchly-site` على جهازك، **حددي كل اللي جواه** (Ctrl + A) واسحبيه وارميه في صفحة GitHub.
   > مهم: ارفعي **محتوى** الفولدر، مش الفولدر نفسه. لازم `build.js` يبقى في أول الصفحة على GitHub، مش جوه فولدر.
   > لو ملف `.pages.yml` ما ظهرش في جهازك (ملفات بتبدأ بنقطة بتبقى مخفية أحيانًا)، فعّلي "إظهار الملفات المخفية" أو ارفعيه لوحده بعدين.
5. تحت دوسي **Commit changes**.

## الخطوة ٢ — انشري الموقع على Cloudflare Pages

1. اعملي حساب على **dash.cloudflare.com** (مجاني).
2. من القايمة: **Workers & Pages** ← **Create** ← اختاري تبويب **Pages** ← **Connect to Git**.
3. اربطي حساب GitHub واختاري الـ repo `watchly`.
4. في إعدادات البناء:
   - **Framework preset:** `None`
   - **Build command:** `node build.js`
   - **Build output directory:** `dist`
5. دوسي **Save and Deploy**، واستني دقيقة.
6. هيديكي رابط زي `watchly.pages.dev` — ده موقعك 🎉

بعد كده **أي تعديل على GitHub بيتنشر لوحده** خلال دقيقة.

## الخطوة ٣ — لوحة التحكم (Pages CMS)

1. ادخلي **app.pagescms.org** ودوسي **Sign in with GitHub**.
2. هيطلب يتثبّت على حسابك — اختاري الـ repo `watchly` بس ووافقي.
3. افتحي `watchly` من القايمة، هتلاقي قسمين:
   - **الأفلام والمسلسلات** — تضيفي وتعدّلي الأعمال
   - **إعدادات الموقع** — الاسم، الإيميل، أكواد الإعلانات، صفحات من نحن والخصوصية
4. أول حاجة: افتحي **إعدادات الموقع** وغيّري **رابط الموقع** لرابطك الحقيقي من Cloudflare، وحطي إيميلك.
5. امسحي العمل التجريبي "مثال تجريبي (امسحيه)".

**كل ما تدوسي Save في لوحة التحكم ← بيتحفظ في GitHub ← Cloudflare بيبني الموقع من جديد ← التعديل يظهر خلال دقيقة.**

### إزاي تضيفي مسلسل جديد
- **Add an entry** في "الأفلام والمسلسلات"
- **الاسم:** من غير كلمة "مسلسل" أو "فيلم" (الموقع بيضيفها لوحده)
- **الرابط (slug):** بالإنجليزي وبشرطات، مثال `khamsin-khamsin-2026`
- **القصة والرأي:** اكتبيهم بأسلوبك — ما تنسخيش من مواقع تانية
- **تتفرج فين:** اسم المنصة + رابط العمل عليها + (اشتراك / مجانًا)
- **فيديوهات:** الصقي رابط يوتيوب العادي للإعلان الرسمي، والموقع بيحوّله لوحده
- **ملخص الحلقات:** زوّدي حلقة كل ما تنزل
- **الصور:** خدي البوستر الرسمي من صفحة العمل على TMDB أو المادة الدعائية الرسمية

## الخطوة ٤ — جوجل

1. ادخلي **search.google.com/search-console** ← **Add property** ← اختاري **URL prefix** واكتبي رابط موقعك.
2. للتوثيق اختاري **HTML tag**، انسخي سطر `<meta ...>` وحطيه في **إعدادات الموقع ← أكواد الإعلانات ← كود في الـ head**، احفظي، استني دقيقة، وارجعي دوسي **Verify**.
3. من **Sitemaps** اكتبي `sitemap.xml` ودوسي **Submit**.

## الخطوة ٥ — الإعلانات

| المرحلة | الشركة | الكود بيتحط فين |
|---|---|---|
| البداية | Adsterra أو Monetag | "كود آخر الصفحة" أو "إعلان جوه صفحة العمل" |
| بعد ما المحتوى يكتر | Google AdSense | "كود في الـ head"، ولما يتقبل: إعلان في "إعلان جوه صفحة العمل" |
| ملف ads.txt | أي شركة بتطلبه | خانة "محتوى ملف ads.txt" |

الصفحات اللي AdSense بيطلبها (من نحن، الخصوصية، اتصل بنا) **موجودة جاهزة** — عدّلي نصوصها من إعدادات الموقع.

## خريطة الملفات (لو حبيتي تتعلمي)

```
build.js            ← المولّد: بيقرا المحتوى ويطلّع صفحات HTML جاهزة في dist/
content/site.json   ← إعدادات الموقع
content/works/      ← كل عمل في ملف JSON
assets/style.css    ← التصميم (الألوان في أول الملف)
assets/app.js       ← الهيدر، المشغل، البحث
images/             ← الصور اللي بترفعيها من لوحة التحكم
.pages.yml          ← شكل لوحة التحكم وخاناتها
```

تجربة على جهازك (لو عندك Node.js): `node build.js` وبعدين `npx serve dist` وافتحي الرابط اللي هيظهر.
